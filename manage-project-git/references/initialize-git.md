# 首次 Git 初始化

只在使用者要求第一次初始化時讀取；套用主 Skill 的安全檢查與停止條件。

1. 確認目標目錄與所有一般／隱藏項目，排除誤在上層儲存庫、巢狀 repo、submodule 或 worktree 中操作。已有正確儲存庫時回主檔流程，不重新初始化。
2. 檢查預計追蹤內容與敏感／多餘檔案。保留既有 `.gitignore`，增量補上獨立 `TODO.md`、`docs/PRD.md`、`docs/private/` 及真實環境機密、已確認產物的規則；PRD／TODO 例外依主檔公開條件。不得排除必要來源。
3. 使用已指定分支；未指定時用 `main` 並說明。執行 `git init -b <branch>`；舊 Git 採非破壞性等價方式。
4. 只有使用者提供或確認 URL 且要求設定遠端時才新增 remote，不自動建立託管儲存庫。建立託管儲存庫另需平台、名稱、擁有者及公開性明確；已授權操作中的參數選擇優先用 `request_user_input`，尚未授權的遠端設定／建立另依當前規則取得授權。工具不可用或明確禁止該類提問時才退回對話，不僅因禁止權限請求就退回參數選擇。
5. 只要求 init 就回報到此。首次 commit／push 需有相應授權；要求已包含這些動作時不重複取得授權，按主檔檢查、精確暫存、確認 commit message 內容與交付。遠端已有不同歷史時停止，不合併不相關歷史或強制推送。

初始化不隱含專案骨架、框架、LICENSE、remote、commit 或 push。
